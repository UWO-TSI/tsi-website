- Shots: `withlock.sh devserver specs/evidence/rod-titanium/r2/serve.sh node specs/evidence/rod-titanium/r2/shots.mjs` with `ONLY=look|stages|cut|clips|cards` (`OUT=` must be absolute); serve.sh starts `next dev -p 3484` in its own process group with Supabase blanked and the new world, and stops it after. In hand: `serve.sh node specs/evidence/rod-titanium/r2/hand.mjs <dir> name=<rod glb>@day|night@140,8,0.25` (`CLIP=440,250,400,420`, `VIEW=390x844` for a phone). Icons: `serve.sh node web/scripts/render-icons.mjs rod_titanium rod_titanium_a1`. Use `GPU=1` (headless Metal) so the thin film renders as on a GPU. The devserver lock is contended: a run often waits past the 600 s Bash limit and goes to the background; a run that waited 20 min exits 75, so retry it.
