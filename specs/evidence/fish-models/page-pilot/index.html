Fish models: pilot 5 (river)

The first fish through the new pipeline: concept views on ElevenLabs, one Meshy multi-image run each, and the RAW Meshy model as it came out, before any Blender edit. Stylised realistic. Approve a raw model and it goes to the Blender hand edit (600 to 2,000 triangles, one texture, the remodel's sheen); redo with a note and the views get fixed first. The top views were not fed to Meshy: the image model drew the median fins as side pairs from above, so Meshy got side, front and the mirrored far side.
