web/scripts/pack-glbs.mjs on the 229 GLBs the island and the title load before you can move (the characters' aside,
which sync-character-assets.mjs copies from art as they are): 217 packed, 12 with nothing to gain. raw 31.50 -> 27.59 MB, brotli (q9) 13.44 -> 10.20 MB.

Lossless only: meshopt's vertex codec and index sequence codec on each buffer view as it is (no quantizing, filters or
reordering; gltf-transform's writer was tried first and rejected: it rotates triangles and drops near-identity node
rotations), PNG images to lossless WebP; each kept only where brotli serves it smaller.

same-glb.mjs, every file loaded from the originals and from the packed copies by three's GLTFLoader in headless
Chromium, compared as the game gets it (node transforms, attributes, indices, morphs, materials, texture settings and
texels, skins, animation tracks) and in four renders each, byte for byte:

```
229 of 229 GLBs identical as the game loads them (data, texels and four renders each); 0 differ
the model's share of its renders: least 0.1%, median 16.7%; none drawn in 0
```

vs step 4). Differing pixels: 8,791 (4,637 beyond 3%), against 10,846 (4,378) between two runs with the same
original files (r2s2shot vs r2s4before): the clock, the water, the grass and the lamps' flicker move between runs.
